CrystalForge 0.8 - Crystal-growth experiments and scientific utilities

Run the standalone EXE, or extract the ZIP and open crystal-forge.exe.
Windows 10/11 x64 with an OpenGL-capable driver is required. Rust, Python,
.NET, WebView2 and a separate SQLite installation are not needed to use it.

1. On first launch, enter Full name and optionally choose a User picture.
   Windows opens a native file picker. PNG/JPEG files under 10 MiB are supported;
   dropping a file onto the profile form or entering its path also works.
   Pictures are copied into the local profile; initials appear when no picture is used.
2. Existing experiments and notes belong to the first profile created for this
   data folder. Their database stays in place. Later profiles start empty.
3. The active name/picture appear above Workspace in the sidebar. Profiles lets
   you create/switch profiles or edit your identity. Switches protect unsaved notes.
4. CVT Experiments > + New experiment > Conditions: enter temperatures, date and
   optional name/thermal character. Materials & transport agent holds the optional
   descriptions, element selection and transport-agent text. Save experiment.
5. Click its bar or name to open the log. Experiment details are on the left of the
   header and navigation controls at the upper right. Notes and the editor are below.
   Use Write to edit Markdown, select text and use formatting buttons, or type the
   syntax directly. Preview renders the current draft. Save entry or Ctrl+S saves
   the exact source locally. See docs/MARKDOWN.md for supported syntax.
6. Each note card has Delete note. Delete all notes clears only this profile's log.
   Recently deleted restores saved records. Discarded unsaved edits cannot be restored.
7. Scientific Utilities > Peak Explorer separates EDX characteristic energies
   from XRD reflections. Select elements/phases, inspect sources and change the
   XRD radiation or Sb2Se3 setting. Save / export reference snapshot saves to this
   profile's experiment log or exports folder. Manual XRD keeps the earlier calculator.
   EDX covers Sb, Bi, Se, I, Cl, Br and S. XRD covers Sb2Se3, Sb and trigonal Se.
   No SbSeI or SbI3 diffraction references are bundled. See docs/PEAK-EXPLORER.md.

Default complete data folder: %LOCALAPPDATA%\CrystalForge
An existing %LOCALAPPDATA%\ResearchMinion folder is opened in place so earlier
profiles, experiments and notes remain available after the rename.
It contains profiles.sqlite3, profile subfolders and any earlier root database.
JSON reference exports are stored in the owning profile's exports subfolder.
Keep the WHOLE folder when replacing the executable or making a backup. Save and
close ALL app instances before copying it, including all WAL/SHM files if present.
Copying only one research database does not preserve all users or their pictures.

Profile catalog schema: 1. Research database schema: 4.
Use version 0.5 or later to select profiles. Earlier versions do not understand
profile identities or automatically find new profile databases. These are offline
local profiles without passwords, encryption, or an online account service.

Save is explicit. Unsaved notes/tool inputs do not survive forced shutdown.
Tool drafts stay in memory under their profile while the app remains open.
Attachments, automatic backups, autosave/crash recovery and edit history are pending.

71 automated tests and Linux desktop checks pass. This executable was cross-built
for Windows. Native Windows execution, the native picture picker, MSVC packaging
and Windows accessibility/DPI checks remain unverified here. See docs/VALIDATION.md.
