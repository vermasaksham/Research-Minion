Research Minion 0.4.1 - clearer forms and individual note deletion

Extract the ZIP, then double-click research-minion.exe, or use the standalone EXE.
Windows 10/11 x64 with a working OpenGL graphics driver is required. No account,
Rust, Python, .NET, WebView2 or separate SQLite installation is needed to use it.

1. CVT Experiments > + New experiment > Conditions: enter a name, experiment date
   (YYYY-MM-DD; blank if unknown), and source/sink temperatures in degrees C.
2. Choose thermal character. Open Materials & transport agent for optional
   precursor/product formulas or names. Confirm
   element suggestions or use the periodic table. Transport agent is optional.
3. Save and click the experiment bar or name to open its own log. Save entries
   with Save entry or Ctrl+S. Back to experiments is at the top of the log.
4. Every saved note card has Delete note; the editor has Delete this note.
   Delete all notes clears the whole log; Delete experiment hides it and its log.
   All require confirmation. Restore records from Recently deleted on the overview.
   Unsaved edits discarded during deletion cannot be restored.
5. Tools > Peak Explorer: enter your own orthorhombic a/b/c cell in Angstrom,
   wavelength, and selected h k l lines. Enter the source and axis convention.
   This initial tool provides d-spacings, Bragg angles, position-only markers,
   and forward/inverse Bragg calculators. Choose an experiment and date to save
   inputs/results/provenance/interpretation into its log as a new entry.
6. No original Sb/Se EDX dataset, reference cell catalog, systematic-absence
   filtering or automatic Pbnm/Pnma conversion is included. Do not use the
   orthorhombic metric for other crystal systems. See docs/PEAK-EXPLORER.md.

Default data: %LOCALAPPDATA%\ResearchMinion\research-minion.sqlite3
Replacing the executable does not require deleting the data folder.
Versions 0.4 and 0.4.1 share schema 4 and are compatible with the same database.
Versions 0.1-0.3 cannot open a database upgraded to schema 4. Old experiment dates remain unknown.
Previous unlinked project notes stay under Previous project logs on the overview.

Save is explicit. Tool inputs last only while the app is open; save analyses to
retain them. Recently deleted retains saved records without automatic expiry;
it is not backup or edit history. To make a manual safety copy, save and close
all instances, then copy the whole data folder, including WAL/SHM files if present.
Attachments, automatic backups, autosave/crash recovery and edit history are pending.

43 automated tests and Linux UI checks pass. This executable was cross-compiled
for Windows. Windows execution, MSVC packaging and Windows accessibility/DPI
